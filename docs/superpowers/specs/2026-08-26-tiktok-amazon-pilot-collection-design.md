# TikTok 排行榜到 Amazon 妙手采集：首轮验证设计

## 目标

使用 `tiktok_category_ranking_20260824_035703(1).xlsx` 中的五金工具排行榜数据，先筛选一个测试商品，在 Amazon 美国站找到符合条件的商品，并通过 Chrome 中的妙手插件完成一次成功采集。本轮不做商品优化，不处理品牌词或 Logo。

## 输入与范围

- 数据源：工作表“商品排行榜”，共 2,936 条商品记录。
- 数据字段：三级类目、商品图片 URL、当前排名、排名变化、TikTok 评分、评价数量、最高价格、最高成交金额、最高点击量和最高点击率。
- 表格没有商品名。本轮以商品图片和类目识别商品类型，不要求先与外部商品名对比。
- 首轮只采集 1 个商品；成功后再扩展到原定 3 个。
- 品牌和 Logo 不作为本轮筛选条件，也不由执行方删除或修改。

## 候选筛选

### 合规和履约硬过滤

排除武器或自卫用品、刀具、开锁或盗窃辅助工具、危险化学品、喷雾、高功率激光、隐藏摄像和隐私监控商品。排除需要额外资质或危险品处理的商品，包括焊枪和烙铁，以及首轮中的电池和复杂电器。排除召回品、二手或开箱商品，并优先选择结构简单、尺寸较小、用途清晰、售后风险较低的普通工具。

### TikTok 数据综合判断

在通过硬过滤的候选中综合判断：

- 最高成交金额：30%
- 当前排名：25%
- 最高点击量：15%
- 最高点击率：10%
- TikTok 评分和评价数量：10%
- 图片清晰度、可识别度和商品结构简单程度：10%

相同图片 URL、明显同款或仅颜色规格不同的候选只保留一个。后续用户提供店内历史商品表后，在采集前增加“商品类型、图片相似度、Amazon ASIN”三层去重。

## Amazon 验证

1. 使用 TikTok 商品图片在 Amazon 美国站执行图片搜索。
2. 如果 Amazon 图片搜索不可用，先暂停并说明可用的替代检索方式，不擅自切换流程。
3. 候选 Amazon 商品必须当前可售，目标规格有库存。
4. Amazon 评价数量必须严格大于 20。
5. Amazon 评分必须严格高于 4.0。
6. Amazon 主图、商品结构和用途应与 TikTok 图片对应；本轮不要求先进行商品名对比。

## 妙手采集

在 Amazon 商品通过全部检查后，通过用户 Chrome 中已经安装并登录的妙手插件发起采集。正式点击会创建妙手侧数据，因此在动作发生前展示商品、ASIN、评分、评价数和选择理由，并获得用户的最后确认。以妙手界面出现明确的采集成功状态或成功提示作为完成依据。

## 异常处理

- Chrome、Amazon 登录或妙手插件不可用：停在当前页面，请用户完成登录或插件准备。
- Amazon 图片搜索不可用：报告页面状态和可选替代方案，等待确认。
- 候选不满足评分或评价数：返回候选池继续筛选，不降低硬性阈值。
- 商品属于受限或高风险类型：淘汰并记录原因，选择下一候选。
- 妙手出现字段选择、店铺选择、覆盖确认或异常提示：不猜测关键选项，展示当前状态并请用户确认。

## 成功标准

- 选出的 Amazon 商品满足评分严格高于 4.0、评价数量严格大于 20、可售且与 TikTok 图片对应。
- 用户在采集前看到关键商品信息并确认。
- 妙手插件显示明确的采集成功结果。
- 本轮没有修改源表，没有执行商品优化，也没有删除品牌词或 Logo。
