# 订单利润核算桌面界面设计

## 目标

为现有订单利润核算程序提供一个标准 Windows 桌面界面，并通过 PyInstaller 打包为无需安装 Python 的 `订单利润核算.exe`。界面只负责输入目录、展示运行状态和打开结果，利润计算继续复用现有核心逻辑。

## 用户流程

1. 用户双击 `订单利润核算.exe`。
2. 程序默认打开 exe 所在目录，也允许通过“选择目录”选择新的数据目录。
3. 程序自动识别最新的 `导出订单包裹*.xlsx/csv`、`采购订单.xlsx/csv` 和可选的 `商品表.xlsx/csv`，并显示识别结果。
4. 用户点击“开始核算”。核算期间按钮禁用，界面显示处理中和日志。
5. 完成后显示主订单数、盈利订单数、亏损订单数、待核对订单数和利润合计，并提供“打开结果文件”按钮。
6. 用户可继续选择另一个目录重复核算。

## 界面结构

使用 Tkinter 标准控件，不依赖浏览器或第三方 GUI 框架。

- 顶部：工作目录输入框、“选择目录”按钮、“刷新文件”按钮。
- 文件区：主表、采购表、商品表三行文件识别状态；商品表缺失显示“未提供（可选）”。
- 操作区：“开始核算”按钮和当前状态文本。
- 统计区：主订单、盈利、亏损、待核对、利润合计五个统计项。
- 日志区：只读多行文本框，显示识别、核算、输出路径和错误信息。
- 底部：“打开结果文件”按钮；没有成功生成结果前禁用。

窗口关闭时，如果核算线程仍在运行，先等待线程结束再退出，避免生成半成品文件。

## 线程与错误处理

Tkinter 主线程只负责界面响应；核算在后台线程执行，完成或失败后通过线程安全队列回传主线程更新控件。错误分为：

- 输入文件缺失或无法读取：显示具体缺少的文件名；
- 字段识别、商品 ID 成本冲突或金额解析错误：显示原始错误信息；
- 输出文件保存失败：显示目标路径和系统错误。

失败时保留日志，重新选择目录或刷新文件后可再次运行，不关闭窗口。

## 打包

使用 PyInstaller 生成 Windows 单文件 exe，命令入口为 `hesuan_gui.py`。打包包含 pandas、openpyxl 和 Tkinter 所需运行文件，不需要用户安装 Python。源码目录保留一个开发用启动脚本，exe 是最终用户入口。

打包产物放到 `dist/订单利润核算.exe`。输入文件仍由用户放在 exe 所在目录或界面选择的目录中，输出写入该数据目录的 `输出` 子目录。

## 验证

- 在当前真实订单目录执行 GUI 使用的同一计算入口，核对四个输出 Sheet 和统计值。
- 在 Windows 上执行 PyInstaller 构建并启动 exe，确认可选择目录、开始核算、显示结果并打开输出文件。
