# 订单利润核算

把文件放在本目录后，双击 `运行利润核算.bat`，或在命令行执行：

```powershell
python hesuan_ticheng.py
```

也可以双击 `运行利润核算界面.bat` 打开标准 Windows 桌面界面。界面支持选择工作目录、刷新输入文件、开始核算、查看统计结果和打开生成的 Excel 文件。

如果需要给没有 Python 环境的电脑使用，在本目录执行 `build_exe.bat`，会生成 `dist/订单利润核算.exe`。把这个 exe 放到订单数据目录附近，运行时选择实际数据目录即可。

点击“选择目录”，选择存放原始表格的文件夹，程序根据第一张工作表的第一行表头识别文件，**文件名不限**，支持 `.xlsx`、`.xlsm` 和 `.csv`：

- 主表：包含订单编号和平台回款金额；
- 采购表：包含买家订单号、采购总金额和订单状态；
- 商品表（可选）：包含产品 ID 和产品成本。

同类文件有多份时使用最近修改的一份（修改时间相同优先不带“副本”的文件），核算前请确认界面显示的三个文件名。不扫描子目录，忽略 Excel 临时文件和可识别的核算结果文件；无法识别时在日志显示提示。放在 `dist` 中的 exe 默认选择上一级数据目录；移到其他文件夹时默认选择 exe 所在目录。

结果保存到 `输出/订单利润核算-时间.xlsx`，包含“汇总”“盈利订单”“亏损订单”和“待核对订单”四个工作表。盈利和亏损订单分开显示，亏损明细中的“订单利润”保留负数并以红色显示；明细表不导出下单时间，采用成本、物流成本、订单利润紧跟在平台回款金额右侧。

计算规则：

1. 采购订单号末尾的 `-1`、`-2` … `-n` 会归并到同一个主订单，所有有效子订单的采购成本相加。
2. 采购状态包含“退款”“拒绝”或“驳回”的记录不计入成本，也不计物流；这些记录会在结果中保留排除行数和金额。
3. 有效采购子订单存在时，每个有效子订单扣 `$1` 物流成本。
4. 没有有效采购成本时，按商品 ID 查商品表，用商品成本单价 × 主订单商品数量，并按一个履约单扣 `$1` 物流成本。
5. 采购成本优先于商品表成本。两者都找不到时，利润留空，避免把未知成本误算为零。

利润公式：

```text
订单利润 = 平台回款金额 - 采用成本 - 物流成本
```

可选参数：

```powershell
python hesuan_ticheng.py --folder "E:\\path" --logistics-fee 1
python hesuan_ticheng.py --output "E:\\path\\利润结果.xlsx"
```
